    What this tool is good for

    • Seeing deadlines from several sources in one searchable, sorted place.
    • Noticing when a source changes a date or withdraws a notice, with a record of the change.
    • Telling confirmed information from unknown: no deadline is ever guessed.

    What it cannot do - please read

    • It is not live. Sources are checked on a schedule (the busiest every 60 minutes, the Erasmus catalogue once a day). A change in between will not show yet. The header always says how old the check is.
    • Some deadlines are not published in one place. Erasmus Mundus programmes set their own dates (usually October-January), so they show "deadline not published" - open the programme website.
    • It does not decide eligibility. "Keywords found" only highlights words in the notice text. Read the official announcement.
    • It only covers approved sources. Absence here does not mean a scholarship does not exist.
    • Parsing can be wrong. If a site redesigns its pages, the tracker flags the source as needing review instead of silently dropping notices.
    • Some dates are assumed. If a source gives only a date, we treat it as end of day (23:59) in the source's timezone and mark it "assumed".
    • Time-zone abbreviations are ambiguous (e.g. IST, CST). Check the official page for the exact time.
